METODOLOGÍA VLSM

El sistema ordena automáticamente las redes de mayor a menor cantidad de hosts, calcula los bits necesarios con la fórmula (2ⁿ - 2 ≥ hosts), y genera:

  • Dirección de Red (Network ID)
  • Broadcast
  • Rango de Hosts válidos
  • Máscara de subred
  • Prefijo CIDR
  • Proceso binario paso a paso

¿QUÉ ES VLSM?

VLSM (Variable Length Subnet Masking) es una técnica que permite utilizar máscaras de subred de longitud variable dentro de una misma red, optimizando el espacio de direcciones IPv4 y evitando el desperdicio de IPs.

CÓMO USAR LA HERRAMIENTA

  1. Paso 1: Ingresa la dirección IPv4 base (ejemplo: 192.168.1.0)
  2. Paso 2: Agrega las redes que necesitas con nombre y cantidad de hosts
  3. Paso 3: Presiona el botón "CALCULAR SUBNETEO VLSM"
  4. Paso 4: Visualiza la tabla de resultados y el proceso binario detallado

FÓRMULAS Y CÁLCULOS

Bits de Host

2ⁿ - 2 ≥ Hosts

n = número de bits necesarios
Prefijo CIDR

/32 - n

Donde n = bits de host
Hosts Disponibles

2ⁿ - 2

Hosts utilizables por subred
Siguiente Red

Broadcast + 1

Salto para la siguiente subred

EJEMPLO PRÁCTICO

Datos de entrada:

  • IP Base: 192.168.1.0/24
  • Red A (Ventas): 50 hosts
  • Red B (RRHH): 20 hosts
  • Red C (IT): 10 hosts

Resultado del cálculo VLSM:

  • Red A: 192.168.1.0/26 (62 hosts disponibles)
  • Red B: 192.168.1.64/27 (30 hosts disponibles)
  • Red C: 192.168.1.96/28 (14 hosts disponibles)

PROCESO BINARIO

El sistema convierte los octetos de la dirección IP a binario y aplica la máscara para obtener:

  • Network ID: AND lógico entre IP y máscara
  • Broadcast: OR lógico entre IP y ~máscara
  • Primer host: Network ID + 1
  • Último host: Broadcast - 1
